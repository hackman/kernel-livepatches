CVE fixes

cve-2026-99288-livepatch-6.x.c

CVE-2026-99288 patch ↗ livepatch 6.x

Rejects unhashed sockets in __inet_lookup_established / __inet6_lookup_established after taking a reference, and defers the SYN-cookie reqsk free in tcp_get_cookie_sock. Closes a lockless-ehash SLAB_TYPESAFE_BY_RCU reuse UAF / NULL-deref in tcp_v4_rcv. Auto-adapts to the Ubuntu syn_recv_sock SAUCE prototype. Upstream commit 4e2b3ef19e0e.

cve-2026-99288-livepatch-5.x.c

CVE-2026-99288 patch ↗ livepatch 5.x

Same CVE-2026-99288 fix for the 5.x series (5.4 / 5.10 / 5.15 …) using 5.x APIs: the INET_MATCH/INET6_MATCH macros, the tsoff argument of tcp_get_cookie_sock, and an open-coded hlist_nulls_unhashed_lockless for older trees.

cve-2026-98432-livepatch-6.12.c

CVE-2026-98432 patch ↗ livepatch Debian 6.12

Swaps kfree for kfree_rcu in inet_sock_destruct and tcp_v4_reqsk_destructor so inet_opt/ireq_opt survive the SYN-retransmit / reqsk-migration RCU window. Upstream commit e3f33b0a1d89.

cve-2026-98432-livepatch-6.8.c

CVE-2026-98432 patch ↗ livepatch Ubuntu 6.8

The same CVE-2026-98432 fix tuned for Ubuntu 6.8.y. Nearly identical source to the 6.12 variant; both target vmlinux. Pick whichever matches your running kernel.

kvm-mmu-role-fix-livepatch.c

CVE-2026-53359 patch ↗ livepatch v6.0+

“Januscape” fix: KVM shadow-paging use-after-free from a missing role.word check in kvm_mmu_get_child_sp. Upstream commit 81ccda30b4e8 (function introduced by 2e65e842c57d).

kvm-mmu-role-fix-livepatch-4.18.c

CVE-2026-53359 patch ↗ livepatch audit only 4.18 / RHEL 8

Pre-5.1-API audit livepatch wrapping kvm_mmu_get_page on RHEL 8 / clones. 4.18 is structurally exposed to the same UAF class, but this module only adds visibility — it does not close the implicit-descent reuse path. See the file header before relying on it.

kvm-mmu-role-fix-ftrace-3.10.c

CVE-2026-53359 patch ↗ ftrace audit only 3.10

Defence-in-depth ftrace audit hook on 3.10's kvm_mmu_get_page. Same caveat as the 4.18 module: catches allocation duplicates but not the implicit-descent reuse in FNAME(fetch).

nft-catchall-fix-livepatch.c

CVE-2026-23111 patch ↗ livepatch

Fixes a use-after-free in nft_map_catchall_activate in the netfilter nftables subsystem. Livepatch for modern kernels, validated with the included PoC test scripts.

nft-catchall-fix-livepatch-4.18.c

CVE-2026-23111 patch ↗ livepatch 4.18 / RHEL 8

The CVE-2026-23111 fix built against the pre-5.1 livepatch API for RHEL 8 and its clones; rmmod cleans up with no sysfs dance.

badepoll-livepatch.c

CVE-2026-46242 patch ↗ livepatch

“BadEpoll” fix: use-after-free in the epoll ep_remove() path. See badepoll-livepatch-example.c for a minimal annotated companion.

Hardening & mitigations

ptrace-fix-livepatch.c

patch ↗ livepatch

Mitigates the ptrace-after-exit_mm() dumpability bypass (the “ssh-keysign” chain, upstream commit 31e62c2ebbfd). When task->mm is NULL it requires CAP_SYS_PTRACE in the init namespace instead of silently skipping the dumpable gate.

ptrace-fix-ftrace.c

patch ↗ ftrace

The same ptrace exit_mm() mitigation implemented with dynamic ftrace + IPMODIFY for kernels without livepatch infrastructure.

Generic tools & examples

block-functions.c

ftrace utility

Generic blocker: replaces a configurable list of functions with an -EPERM stub via dynamic ftrace + IPMODIFY. Edit blocklist[] at the top of the file.

livepatch-filter.c

livepatch utility

Same generic -EPERM blocker as block-functions.c, implemented via livepatching. Edit blocklist[] to choose the functions to neutralise.

stealth-livepatch.c

ftrace utility

An ftrace redirect that registers no entry under /sys/kernel/livepatch/ — unload is a plain rmmod. Useful when you don't want the patch to advertise itself.

tcp-connect-logger.c

livepatch example

The worked example from the livepatching guide: wraps tcp_v4_connect() with a sysfs-toggled connection logger.

udp-send-logger.c

livepatch example

Sister module to the TCP logger: logs outgoing UDP/IPv4 datagrams by livepatching udp_sendmsg.
